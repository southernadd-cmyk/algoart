# Retired town-square HDRI source note

The earlier test-tower prototype used the HDRMAPS **Jedlina-Zdrój Plac Zdrojowy** panorama (source: https://hdrmaps.com/freebies/jedlina-zdroj-plac-zdrojowy/).

The JPG `jedlina-zdroj-1k.jpg` was unused by the current shared live/test renderer and was removed from the current repository branch on 29 October 2026. It is not included in subsequent GitHub Pages builds. The tower uses its own procedural backdrop. Do not restore the old JPG or add it to the published site without confirming reuse rights.

Historical commits may still retain the previous asset. This README is kept as a provenance note only.
