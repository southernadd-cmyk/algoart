# ALGO/ART Reel Series

Eight short vertical explainers showing the rules behind ALGO/ART in plain English.

## Series philosophy

> **“The idea becomes a machine that makes the art.”**  
> — Sol LeWitt

This is the framing statement for the series, not a caption repeated on every reel. Use it as a restrained opening to Reel 01 or, preferably, as the closing statement of Reel 08 / the complete eight-film sequence.

Final series card:

**ALGO/ART**  
**Eight ideas. Eight machines for making art.**

*Mathematics sets the rules. The marker breaks them.*

## Format

- 9:16 vertical, designed for Instagram Reels / Threads video
- approximately 20 seconds each
- same visual identity across all eight
- open with the finished artwork or system name
- strip the image back to its hidden construction rule
- explain one mathematical idea only
- rebuild/reveal the artwork
- end on: **RULES + SEED → ART** / **ALGO/ART**
- use real gallery artworks where a strong example exists
- narration and on-screen copy must work independently, so the reel remains understandable muted

## 01 — Golden Field / Orbital Studies

**Hook:** This isn't random placement.

**Plain-English idea:** The generator tries arrangements of large, medium and small forms. Golden-ratio focal points, spacing, protected empty space and a scoring system help it choose a composition that feels balanced.

**Visual sequence:** Finished work → 38.2/61.8 grid → four φ focal points → hero/medium/small forms → several ghost candidate positions → chosen arrangement → finished marker rendering.

**On-screen copy:**
- THIS ISN'T RANDOM PLACEMENT
- 61.8 / 38.2
- HERO / MEDIUM / SUPPORT
- TRY → SCORE → CHOOSE
- SAME SEED = SAME ART

## 02 — Golden Spiral / Golden Trajectories

**Hook:** Every quarter turn, this spiral grows by φ.

**Plain-English idea:** V4 follows a logarithmic golden-spiral growth law. Marks are placed along that trajectory and can be rotated with its movement.

**Visual sequence:** Centre point → clean spiral draws on → quarter-turn radius markers → ×φ label → artwork grows along trajectory → Reveal φ overlay → final work.

**On-screen copy:**
- A SPIRAL WITH A RULE
- +90° → RADIUS × 1.618
- BUILD ALONG THE PATH
- MATHEMATICS → MARKER

## 03 — Recursive Rectangles / Recursive Divisions

**Hook:** One rectangle. Split it 61.8 / 38.2. Repeat.

**Plain-English idea:** The canvas is recursively divided near the golden ratio. Those divisions become territories for shapes, lines and deliberate empty space.

**Visual sequence:** Blank rectangle → first 61.8/38.2 cut → repeated cuts → some cells fade to voids → marker forms populate cells → final artwork.

**On-screen copy:**
- START WITH ONE RECTANGLE
- SPLIT 61.8 / 38.2
- SPLIT AGAIN
- SOME SPACE STAYS EMPTY
- SIMPLE RULE → COMPLEX IMAGE

## 04 — Fibonacci Burst / Radiant Systems

**Hook:** Don't divide a circle evenly.

**Plain-English idea:** Marks radiate from one or more hubs. Instead of ordinary equal-angle spokes, the system can move toward the golden angle and place marks at φ-related distances.

**Visual sequence:** Hub → ordinary equal spokes briefly shown/crossed out → golden-angle stepping → φ-scaled radii → shapes appear → final burst.

**On-screen copy:**
- NOT AN EVEN STARBURST
- GOLDEN ANGLE ≈ 137.5°
- φ-SCALED DISTANCES
- REPEAT WITHOUT REPEATING

## 05 — Phi Network / Connected Fields

**Hook:** First place the points. Then decide which relationships matter.

**Plain-English idea:** Nodes inherit φ-based positions and hierarchy. The graph builds a backbone, adds useful secondary links and avoids unnecessary crossings.

**Visual sequence:** Nodes appear → hero nodes highlighted → primary backbone draws → candidate links flash → crossing-heavy links disappear → secondary links settle → artwork reveal.

**On-screen copy:**
- PLACE THE NODES
- BUILD THE BACKBONE
- REWARD φ-LIKE DISTANCES
- AVOID THE TANGLE
- STRUCTURE → NETWORK

## 06 — Organic / Growth Systems

**Hook:** This plant never grew. The rule did.

**Plain-English idea:** A branch grows, then the next generation becomes roughly 1/φ as long. Golden-angle-derived turns and repeated branching create a plant-like hierarchy.

**Visual anchor:** **Growth Systems — Study 15 / V4 / AA-20261005-03-55769**.

**Visual sequence:** Final Study 15 glimpse → root point → first branch → label L → next branch labelled L/φ → branches repeatedly shorten → golden-angle turn graphic → whole skeleton → imperfect marker rendering → final Study 15.

**On-screen copy:**
- THIS PLANT NEVER GREW
- THE RULE DID
- NEXT LENGTH ≈ LAST LENGTH ÷ 1.618
- TURN / BRANCH / REPEAT
- SAME SEED = SAME GROWTH
- RULES + SEED → ART

**Voiceover:**
“Nothing here is being painted by an image AI. The system starts at a root and grows a branch. Each new generation becomes roughly one over phi as long, while golden-angle turns change its direction. Repeat the rule with the same seed, and you get the same growth every time.”

## 07 — Geometric / Constructed Forms

**Hook:** Not a grid. A composition.

**Plain-English idea:** Independent geometric forms are sized, positioned and rotated using φ relationships. Different composition families create balance, stacks, axes, collisions, floating space or cropped forms.

**Visual sequence:** φ focal points → two hero forms → supporting shapes → size relationships → rotation → alternative family silhouettes → chosen final composition.

**On-screen copy:**
- NOT A GRID
- SIZE WITH φ
- POSITION WITH φ
- ROTATE / BALANCE / CROP
- CONSTRUCT THE COMPOSITION

## 08 — Controlled Scribble / Automatic Marks

**Hook:** It looks like a scribble. It isn't random.

**Plain-English idea:** Invisible φ-distributed territories give the pen anchors, limits and flow directions. Golden-angle turns and deliberate restarts create gesture while protected regions preserve gaps.

**Visual sequence:** Finished scribble → fade to invisible territories → anchors → arrows showing flow → pen travels → boundary pulls it back → deliberate gap → final artwork.

**On-screen copy:**
- LOOKS RANDOM
- ISN'T RANDOM
- INVISIBLE TERRITORIES
- GOLDEN-ANGLE TURNS
- CONTROLLED GESTURE
