graffiti alphabet · A–Z

Twenty-six independently constructed graffiti capitals, each with its own gesture paths, hooks and endings. This is a complete original A–Z draft, built as part of the SKUF research—not a traced or authenticated alphabet by SKUF.

The Bombing Science 61-artist A–Z collection informed the approach: each letter needs individual anatomy, not a shared font skeleton.

A–Z

Words

What this is

The letters are actual authored vector gestures, not a browser font with a texture applied. The text setting arranges those paths into words; a seed changes small proportions and placement without swapping the letter constructions.

This draft is for checking letter anatomy and whether unfamiliar words still work. It isn't part of the production tower yet. This is the first completed construction set, not yet one of the eight approved writer-specific alphabets.
