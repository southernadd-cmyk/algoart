Maps extracted from the user's uploaded GLB and recompressed to 1024px WebP.
Color uses sRGB; normal and roughness use linear data. Roughness is extracted
from the original packed metallic/roughness texture's green channel.
The sample box geometry is not used. A 1.8m repeat is aligned across the
existing reception floor pieces on both the live and test towers.
