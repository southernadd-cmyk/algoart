# Graffiti V3 — isolated material proof of concept

Development branch only. No production gallery modules, bundles or atlases modified.

- Uses the versioned V2 letter geometries and word-flow rules.
- Tests deterministic pressure, speed, contact gaps, centre-core spray density and edge flecks.
- Tests distinct painted plaster, rough plaster and brick/mortar response.
- Renders comparative study cards across all nine styles.
- **Known gaps before release:** SVG filled-wedge region deposition; proper per-word orbit gestural layer; measured wall UV coordinates and PBR texture integration; in-situ close/distance captures; mobile/desktop atlas memory benchmarks; source-sheet style review; historic backfill and daily generation verification.
- Keep all production work blocked until those gates pass.
