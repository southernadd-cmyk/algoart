# V5h — distinct source-guide relationships, not post-hoc puzzle splitting

**Experiment only. Do not deploy.**

## Regression corrected

V5g first unioned multiple independently meaningful source-guide territories into a global filled raster mask, then called each connected component an area. That erased original φ/source relationships and reduced Growth / Golden Trajectories / Constructed to 2 / 1 / 1 mega-fields.

V5h skips **all** V5e/V5f/V5g field planners. It invokes frozen **V5d source-guide interpretation directly**:
- Growth: real `guide.segments` with recorded branch and depth, connecting only plausible related branch territories.
- Golden Trajectories: ordered `guide.points`, retaining actual arm identities and local positions, excluding cross-arm connections.
- Constructed Forms: actual `guide.items` with tiers, size and position, connecting genuine focal/supporting object territories.
- Recursive Divisions: original golden-ratio `guide.cells`, no extra processing.

Each proposed region is a bounded connected surface joining **two distinct source-guide territories**; RGB comes from their original material-neutral local pigment records. Every field records BOTH guide IDs, reference path IDs, relation kind, guide role and occupied-area cells. Reciprocal duplicate pairings are rejected. No arbitrary field count subdivision, random patch generation or global occupancy merging.

Strict tests require >=4 original guide-derived connected painted areas, all unique unordered geometry pairs, area caps, source provenance, deterministic image pixels and unchanged Recursive Divisions.

**Visual assessment: HOLD.** Although these are now true distinct guide pairs rather than a reconstructed global puzzle, some painted shapes overlap enough that their flat preview still reads as only **two or three conspicuous colour masses** rather than four or more. This fails the *visible* interpretation goal; source-link count alone is not an artistic acceptance check. Next work must respect actual guide group separation and control obscuration by already source-owned areas, **not** subdivide the result of a global field mask into arbitrary fragments.
