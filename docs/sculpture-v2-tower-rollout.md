# Sculpture V2 tower rollout — guarded implementation

## Isolation
- Public tower imports gallery/visit/sculpture-render-traced.mjs and V1 packs.
- Preview route: gallery/sculpture-v2-test/ (generated by the builder).
- Only the preview builder substitutes gallery/sculpture-v2-test/sculpture-render-v2.mjs.
- Geometry snapshot is frozen under gallery/sculpture-v2-test/engine/, copied
  from the approved V4.2.1 Sculpture Lab. All five modules are version-locked, except an explicitly documented
  V2-only micro-island coverage fix (see below).
- On-demand preview reconstruction is temporary. It is **not** the proposed
  loading architecture for the final V2 production tower.
- Preview never updates dated gallery/3d/sculptures.json.gz or publishing jobs.
- Confluence portrait paintings remain excluded from the statue pipeline.
- Museum-pin support is the approved physical attachment.

## Preview build / manual acceptance gate
1. node automation/build-sculpture-v2-test.mjs
2. node --test tests/sculpture-v2-tower-coverage.test.mjs
3. node tests/sculpture-v2-tower.browser.mjs with the local preview server
4. Confirm true archive dates load, mobile/desktop startup, pin, no omitted pixels.
5. Artist inspects preview manually. Functional tests do not take screenshots.
6. Do **not** enable V2 in production until artist approval.

## Later stages, NOT implemented by this preview
- Offline V2 baking: versioned mesh/UV/bump/material manifests with checksums.
- All historical solo portraits baked at desktop and mobile quality.
- Geometry and collision-box auditing; all errors visible, never silent skips.
- Material provenance verification and GPU/memory regression measurements.
- Future daily V2 builder independent of R2/social/daily image creation.
- Production V2/V1 toggle + per-sculpture V1 fallback, with zero-deploy rollback.
- Live deployment after approval and observed successful Pages verification.

## Explicitly out of scope for the first preview
- Replacing the reception's already approved standalone sculpture.
  The isolated adapter intercepts the common renderer, so the test route may
  also render the reception from V4.2 geometry; production requires a separate
  compatibility decision before activation.
- Claiming the test preview is fast enough for production.
- Introducing alternative colours, reshaping the approved V4.2 solids,
  or changing the tower architecture, lift, curator, paintings, or metadata.

### Archive compatibility fix
- Older source paintings sometimes contain 1-pixel pigment islands.
- V2 topology includes these instead of discarding them at the V4.2
  minimum-base threshold. When >48 mobile or >72 desktop regions exist,
  remaining islands are grouped into a final multi-contour region rather
  than omitted. This is the only V2-specific change to frozen lab geometry.

- The V2-only marching-squares minimum area is 0.025 source pixels
  (rather than the lab's 0.25) so isolated source dots survive contour
  triangulation. An explicit tiny-island solid test covers this case.
