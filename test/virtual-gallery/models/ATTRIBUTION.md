# Gallery visitor models

**Human Models Set - Male/Female (Rigged)** by **lzyassoul**. [Original Sketchfab model](https://sketchfab.com/3d-models/human-models-set-malefemale-rigged-7311fcfdc03e4234900eeced42a1e669). Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The browser-ready male and female GLB files are prepared from the non-rigged meshes of the uploaded model; geometry is rescaled for exhibition visitors. The live renderer uses procedural figures when those files are unavailable.

## Additional rigged characters (pending binary deployment)
**Rigged Characters** by **MotionStreamStudios**, [Sketchfab source](https://sketchfab.com/3d-models/rigged-characters-482b7772d3544f70851305212cecc7f1), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The uploaded scene includes two skeletons but no animation clips. It is not yet used to render gallery visitors.

## Corrected male/female rig asset
The `human-male-female-rigged.glb` file is converted from the **lzyassoul** source glTF + BIN without removing the skin data (two 153-joint rigs). Put this GLB in the same `models/` directory. The scene uses small rest-pose adjustments, not the unrelated MotionStreamStudios DEF rig.
